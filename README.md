### Project - Pizza Delivery Optimization – Metaheuristics



This project implements several metaheuristic algorithms to solve the Pizza Delivery Optimization problem. Its goal is to maximize the total score of pizza deliveries by delivering pizzas to teams while maximizing the number of unique ingredients per team.



The project implements three metaheuristics:



* Genetic Algorithm (GA)



* Simulated Annealing (SA)



* Tabu Search (TS)



The solution is implemented in Python using Jupyter Notebook.
